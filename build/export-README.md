# Binder — website export

Everything that makes up **https://binder.red**, organised by type. Generated
from the `binder-site` repo with `make export`; re-run it to refresh. Edit the
site in the repo, not here — this folder is overwritten on every export.

| Folder | What's inside |
|---|---|
| `repo/` | The website's code, cloned from GitHub (`continental-vito/binder-site`). Branch `main` is what is live; `dev` is work in progress. |
| `logos/` | The official brand kit (copied from `3 - Marketing/0 - Logo/Binder-Brand-Kit`): wordmark and icon as SVG and PNG in every variant, favicons, app icons. `LEGGIMI.md` explains which file to use where. |
| `social/` | `link-preview-1200x630.png` — the image shown when binder.red is shared on LinkedIn, X, Slack. |
| `articles/` | The four guides as Markdown: investor list, meet investors, capital raise, founder list. Ready to reuse in posts or newsletters; links point to binder.red. |
| `legal/` | Privacy policy, cookie policy, terms and legal notice. **Drafts:** `[[PLACEHOLDERS]]` mark the company details still needed; not yet published on the site. Have a lawyer review before use. |
| `screenshots/app-founder/`, `app-investor/` | Every screen of the app prototype, both sides, at iPhone 17 resolution (1206 × 2622). |
| `screenshots/site/` | The website's pages and walkthrough steps, desktop and mobile. |
| `fonts/` | Inter, the web font (SIL Open Font License — keep `OFL.txt` with the files). On Apple devices the site and app use the system font (SF Pro). |
